# MyQuantPlatform

주식·ETF 포트폴리오의 목표 비중, 평가손익, 리밸런싱, 위험도와 백테스트를 한 화면에서 관리하는 단일 HTML 웹앱입니다.

## 실행 방법

1. `my-portfolio_5.html`을 내려받습니다.
2. Chrome 또는 Edge에서 파일을 엽니다.
3. 총 투자금액과 달러 환율을 설정하고 종목을 추가합니다.
4. 위험도 분석에서 무료 Twelve Data API 키를 한 번 등록하고 `자동 시세 조회 · 분석 실행`을 누릅니다.

별도의 설치나 서버 실행은 필요하지 않습니다. 입력 내용은 현재 브라우저에 자동 저장되며, 중요한 데이터는 `JSON 백업`으로 별도 보관할 수 있습니다.

## 주요 기능

- KRW·USD 자산 통합 평가
- 목표·현재 비중과 현금 비중 표시
- 목표 투자금액 기준 리밸런싱 계산
- 종목 추가·수정·삭제
- 자산배분 도넛 차트
- 변동성·MDD·누적수익률·CAGR·베타 계산
- 과거 일별 종가 자동 조회 및 종목별 공통 거래일 정렬
- 자동 조회 시 현재가 갱신
- 브라우저 자동 저장
- JSON 백업·복원 및 CSV 내보내기
- 데스크톱·모바일 반응형 화면

## 데이터 안내

과거 종가와 최신 종가는 [Twelve Data](https://twelvedata.com/pricing)의 API를 이용해 브라우저에서 조회합니다. API 키는 사용자의 브라우저 저장소에만 보관되며 GitHub 소스나 JSON 백업에는 포함되지 않습니다. 무료 API의 호출 한도 및 거래소별 제공 범위에 따라 일부 티커는 조회되지 않을 수 있습니다.

자동 조회된 종목은 날짜 교집합으로 거래일을 정확히 정렬합니다. 자동 조회가 지원되지 않는 종목은 기존 수동 입력을 예비 방법으로 사용할 수 있으며, 수동 데이터는 최근 값 기준으로 길이를 맞춰 계산합니다.

상세 확장 계획은 `portfolio-webapp-design-doc.md`를 참고하세요.
