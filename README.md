# MyQuantPlatform

주식·ETF 포트폴리오의 목표 비중, 평가손익, 리밸런싱, 위험도와 백테스트를 한 화면에서 관리하는 단일 HTML 웹앱입니다.

## 실행 방법

1. `my-portfolio_5.html`을 내려받습니다.
2. Chrome 또는 Edge에서 파일을 엽니다.
3. 총 투자금액과 달러 환율을 설정하고 종목을 추가합니다.

별도의 설치나 서버 실행은 필요하지 않습니다. 입력 내용은 현재 브라우저에 자동 저장되며, 중요한 데이터는 `JSON 백업`으로 별도 보관할 수 있습니다.

## 주요 기능

- KRW·USD 자산 통합 평가
- 목표·현재 비중과 현금 비중 표시
- 목표 투자금액 기준 리밸런싱 계산
- 종목 추가·수정·삭제
- 자산배분 도넛 차트
- 변동성·MDD·누적수익률·CAGR·베타 계산
- 브라우저 자동 저장
- JSON 백업·복원 및 CSV 내보내기
- 데스크톱·모바일 반응형 화면

## 데이터 안내

현재가는 직접 입력하는 방식입니다. 실시간 시세 API를 브라우저에서 직접 호출하면 API 키 노출과 호출 제한 문제가 생기므로, 자동 시세 연동은 백엔드 프록시를 추가하는 다음 버전에서 구현하는 것이 안전합니다.

과거 가격은 오래된 날짜부터 최근 날짜 순서로 한 줄에 하나씩 입력합니다. 여러 종목을 함께 분석할 때는 모든 종목의 가격 개수를 동일하게 맞춰야 합니다.

상세 확장 계획은 `portfolio-webapp-design-doc.md`를 참고하세요.
