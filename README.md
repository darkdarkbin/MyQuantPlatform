# MyQuantPlatform

주식·ETF를 검색해 공부하고, 포트폴리오의 실질 분산도·위험·리밸런싱까지 한 화면에서 관리하는 단일 HTML 웹앱입니다.

## 실행 방법

1. `my-portfolio_5.html`을 내려받습니다.
2. Chrome 또는 Edge에서 파일을 엽니다.
3. 무료 Twelve Data API 키를 한 번 등록한 뒤 회사명이나 티커로 종목을 검색합니다.
4. 계획 또는 실제 보유 모드를 선택하고 포트폴리오를 구성합니다.
5. 위험도 분석에서 기간을 선택하고 `자동 시세 조회 · 분석 실행`을 누릅니다.

별도의 설치나 서버 실행은 필요하지 않습니다. 입력 내용은 현재 브라우저에 자동 저장되며, 중요한 데이터는 `JSON 백업`으로 별도 보관할 수 있습니다.

## 주요 기능

- KRW·USD 자산 통합 평가
- 계획 포트폴리오와 실제 보유자산 모드 분리
- 원화·달러 평단 혼용 및 비정상 손익 계산 방지
- 회사명·티커 종목 검색과 주식 리서치 정보
- 선택형 FMP 연동을 통한 ETF 보유종목·섹터·국가 분석
- 목표·현재 비중과 현금 비중 표시
- 추가 투자금·매도 최소화·허용오차·수수료·소수점 거래를 반영한 리밸런싱
- 종목 추가·수정·삭제
- 자산배분 도넛 차트
- 변동성·MDD·누적수익률·CAGR·베타·Sharpe·Sortino 계산
- 종목 간 상관관계 매트릭스와 최대 4개 종목 비교
- ETF 내부 보유종목을 반영한 실질 노출·중복률·집중도 진단
- 종목별 매수 이유·위험·매도 조건·날짜별 투자 일지
- 과거 일별 종가 자동 조회 및 종목별 공통 거래일 정렬
- 1·3·5·10년 기간별 시작일·종료일 강제 적용
- 자동 조회 시 현재가 갱신
- 브라우저 자동 저장
- JSON 백업·복원 및 CSV 내보내기
- 데스크톱·모바일 반응형 화면

## 데이터 안내

종목 검색, 기업 리서치, 과거 종가와 최신 종가는 [Twelve Data](https://twelvedata.com/pricing)의 API를 이용합니다. ETF 내부 보유종목과 섹터·국가 정보는 선택적으로 [FMP](https://site.financialmodelingprep.com/developer/docs)를 사용합니다. 두 API 키는 사용자의 브라우저 저장소에만 보관되며 GitHub 소스나 JSON 백업에는 포함되지 않습니다.

자동 조회된 종목은 날짜 교집합으로 거래일을 정확히 정렬합니다. 자동 조회가 지원되지 않는 종목은 기존 수동 입력을 예비 방법으로 사용할 수 있으며, 수동 데이터는 최근 값 기준으로 길이를 맞춰 계산합니다.

실제 보유 모드의 평균매입가와 현재가는 반드시 선택한 거래통화 기준의 1주당 가격이어야 합니다. 앱은 원화 총매수금액을 달러 평단으로 넣는 등 비정상적인 가격 비율을 감지하면 손익 계산을 중지합니다.

상세 확장 계획은 `portfolio-webapp-design-doc.md`를 참고하세요.
