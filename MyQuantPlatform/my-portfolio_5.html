사용법: GitHub Pages 주소(https://...)로 접속하는 것이 기본 사용 방법입니다. 브라우저 보안 정책상 이 파일을 더블클릭해 file://로 직접 열면 검색·리서치·Google 로그인에 필요한 데이터 요청이 차단됩니다. 로컬에서 열어야 한다면 같은 폴더에서 python -m http.server 같은 간단한 정적 서버를 실행한 뒤 http://localhost:포트로 접속하세요. VS Code는 파일을 보관/편집하는 용도일 뿐, 이 웹사이트 자체는 별도 빌드 없이 이 파일 하나로 완성되어 있습니다.

무료 시세 안내: GitHub Actions가 공개 시장 페이지의 지연 데이터를 하루 한 번 저장하고 사이트는 그 파일만 읽습니다. 공급처 구조 변경이나 일시 차단 시 기존 캐시를 유지하며, 일부 지표가 비어 있으면 ‘정보 없음’으로 표시합니다. Google 로그인 데이터는 Firebase 보안 규칙으로 사용자별 분리되며, 중요한 기록은 JSON 백업도 함께 보관하는 것을 권장합니다. 계산 결과는 투자 판단을 위한 참고 자료이며 수익을 보장하지 않습니다.
