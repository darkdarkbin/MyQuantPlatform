# Signal(MyQuantPlatform) v1.0 RC 작업 중단 시점 테스트 보고서

검증일: 2026-07-24 (세션 한도로 작업 중단, 패키징 직전 최종 재확인)

## 중요 안내

이 보고서는 **v1.0 Release Candidate 작업이 끝나기 전, 세션 한도로 중단된 시점**의 결과입니다.
패키징 직전 마지막 재확인 과정에서, 직전 턴에서 "완료"로 보고했던 작업 중 일부(포트폴리오
대시보드, ETF 자체 성과지표, 기업 상세 히어로 가격, 경쟁사 비교, 480px 모바일 CSS)가 **실제
파일에는 반영되어 있지 않다는 것을 발견**했습니다. 아래 결과는 그 사실을 반영해 **실제 파일을
`grep`으로 재확인한 뒤 다시 실행한 검증**입니다. 자세한 경위와 유실된 항목 목록은
`CURRENT_PROGRESS.md`를 참고하세요.

## 실행한 검증 (현재 파일 상태 그대로, 수정 없이 실행, 모두 통과)

```
node scripts/validate_app.mjs      → app static validation OK: 131 unique ids / 39 inline handlers
python3 scripts/validate_cache.py  → cache integrity OK: 28 detailed tickers / 12308 searchable tickers
node scripts/runtime_smoke_test.mjs → ✅ 런타임 스모크 테스트 전체 통과 (17개 시나리오)
python3 -m py_compile scripts/build_market_cache.py → 문법 오류 없음
```

`runtime_smoke_test.mjs` 17개 시나리오: catalog/manifest 로드, 검색 인덱스, AAPL 검색,
리서치 패널(종합점수·AI요약·해자·적정가), 포트폴리오 종목 추가, 백테스트, 종목비교(펀더멘털 표 포함),
ETF 엑스레이, 포트폴리오 진단(테마·국가·리스크시나리오·AI코치), 적립식 시뮬레이션, 배당 계산기,
관심종목, 오늘의 시장 시그널, 투자일지(복기 알림), 리서치 패널 ETF 분기(QQQ) 확인, 저장/복원
라운드트립. (포트폴리오 대시보드·ETF 자체 성과지표 시나리오는 해당 기능 코드 자체가 유실되어
이번 버전에는 포함되어 있지 않습니다.)

## 이번 세션에서 검증되지 않은 것

- 실제 브라우저에서의 시각적 렌더링(차트 애니메이션, 레이아웃)은 jsdom 기반 런타임 테스트로는
  확인할 수 없습니다. DOM에 올바른 요소가 만들어지고 JS 오류가 없다는 것만 확인된 상태입니다.
- 모바일 레이아웃의 실제 기기/브라우저 육안 확인은 하지 못했습니다.

# Signal(MyQuantPlatform) 3차 업데이트 테스트 보고서

검증일: 2026-07-23

## 핵심 결론

- 검색 랭킹 개선, 신규 기능 13종(종합점수/AI요약/해자/적정가/포트폴리오진단/리스크시나리오/AI코치/종목비교 업그레이드/배당계산기/관심종목/시장시그널/투자일지 업그레이드), AI 어댑터 구조, 파비콘·브랜드를 추가했습니다.
- 이전 세션에서 중단되어 있던 버그 3건(재귀 중첩 `.github` 폴더, 손상된 `DRAM.json` 캐시, 낡은 `workspaceKey` 검증 스크립트)을 수정했습니다.
- 신규 회귀 테스트 스크립트(`scripts/runtime_smoke_test.mjs`)를 jsdom으로 작성해, 브라우저 없이도 앱 전체 흐름을 실제로 실행해 검증할 수 있게 했습니다.

## 정적 검사

- `node scripts/validate_app.mjs`: 통과 (124 unique ids / 39 inline handlers, 유료 API 미사용 확인)
- `python3 scripts/validate_cache.py`: 통과 (상세 캐시 28개, 검색 카탈로그 12,308개)
- `python3 -m py_compile scripts/build_market_cache.py`: 통과

## 런타임 회귀 테스트 (`scripts/runtime_smoke_test.mjs`, 17개 시나리오 전부 통과)

1. catalog.json / manifest.json 로드
2. 검색 인덱스 구축(12,308개) 및 "AAPL" 검색 1위 정확도
3. 리서치 패널: 지표·AI 기업요약·종합점수·경제적 해자·AI 적정가(PER/PEG/DCF) 렌더링
4. 포트폴리오에 AAPL/QQQ 추가
5. 백테스트/위험도 분석(변동성·MDD·CAGR·Sharpe·Sortino)
6. 종목 비교(가격 성과 + 신규 펀더멘털 비교표)
7. ETF 엑스레이(분산 진단)
8. 포트폴리오 진단(테마·국가 노출, 리스크 시나리오, AI 코치)
9. 적립식·목표자산 시뮬레이션
10. 배당 계산기
11. 관심종목(Watchlist) 추가/렌더링
12. 오늘의 시장 시그널(규칙 기반)
13. 투자일지(목표가·매수일 저장, 복기 알림, 메모 추가)
14. 리서치 패널 ETF 분기(QQQ) — 해자/적정가가 ETF에 대해 올바르게 "대상 아님"으로 처리되는지
15. 로컬 보관함 저장 → 복원 라운드트립 데이터 일치

## 발견 후 직접 수정한 버그 (개발 중 단위 테스트로 발견)

- 연차 재무 데이터(`financials.years`)가 최신→과거 순으로 저장되어 있는데 오래된→최신으로 가정해 성장률 부호가 반대로 계산되던 문제
- `financialHealth.equity` 필드명을 `totalEquity`로 잘못 참조하던 문제
- `deepValue()` 헬퍼 사용법 오류로 3개월 모멘텀 값을 못 읽던 문제
- 포트폴리오 리스크 시나리오의 금액 표시가 `totalCurrentValue()`(KRW 환산값)를 USD로 잘못 표시하던 문제

## 알려진 한계 (이번 업데이트 기준, 최신)

- 실적 발표 "예정일" 캘린더는 없고 과거 서프라이즈만 제공합니다.
- 적립식 계산기 복리 그래프, ETF 중복분석 도넛차트 등 시각화는 아직 텍스트/표 형태입니다.
- SPMO/QLD/VUG/SCHQ 상세 데이터는 `data/default-tickers.json`에 등록만 되어 있고, 실제 파일은 GitHub Actions를 한 번 실행해야 생성됩니다(로컬 환경에서는 `api.nasdaq.com`이 403으로 차단됨을 확인).
- AI 기업요약/코치/시장 시그널은 규칙 기반이며, 실제 LLM 연결은 어댑터에 provider를 추가해야 합니다.
- 전체 UI를 토스증권/TradingView 수준으로 재구성하는 작업은 하지 않았습니다.
