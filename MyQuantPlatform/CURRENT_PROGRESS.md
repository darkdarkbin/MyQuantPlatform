# CURRENT_PROGRESS.md — 세션 중단 시점 작업 현황

기록일: 2026-07-24 (Claude 대화 세션 한도로 v1.0 Release Candidate 작업 도중 중단)

## ⚠️ 먼저 알려드릴 것: 작업 도중 일부 변경사항이 파일에 반영되지 않은 채 유실되었습니다

이 ZIP을 만들기 직전, 패키징 전 마지막 확인 차원에서 `validate_app.mjs`/`runtime_smoke_test.mjs`를
다시 실행했는데, 바로 전 턴에서 "완료했다"고 보고드렸던 작업 중 **일부가 실제 파일에는 존재하지
않는 것을 발견**했습니다. 어느 시점에 유실됐는지는 정확히 특정하지 못했지만(코드 편집 도구 자체는
매번 "성공" 응답을 반환했었습니다), 지금 이 문서와 ZIP은 **grep으로 코드 존재 여부를 직접 재확인한
실제 파일 상태**를 기준으로 다시 작성했습니다. 이전 턴에서 "완료"라고 말씀드렸던 아래 항목은
**이 ZIP에 포함되어 있지 않습니다**:

- 포트폴리오 대시보드 카드(건강도 게이지 등, `runPortfolioDashboard`)
- ETF 상세의 자체 CAGR/변동성/Sharpe/MDD/베타 계산(`computeOwnPriceStats`)
- 기업 상세 히어로 가격 영역(`researchHeroPrice`)
- 동일 섹터 경쟁사 바로가기(`renderResearchCompetitors`)
- 480px 이하 모바일 전용 통합 CSS 블록

반대로 ROIC 계산, 8곳의 차트 시각화 연결(자산배분/섹터/국가/테마/ETF중복 도넛, CAGR 막대,
MDD 낙폭, 적립식 복리그래프), 디자인 시스템 1차(그림자/트랜지션/hover/active/focus-visible)는
**실제로 파일에 남아 있는 것을 확인**했습니다. 아래 목록은 이 재확인을 거친 정확한 현황입니다.

## 이번 세션에서 다룬 작업 순서 (요청 순서대로)

1. GitHub 저장소 최초 분석 + 버그 3건 수정 + 검색 개선 + 문서 동기화
2. 신규 기능 15개 요청 중 13개 구현 (AI 어댑터 구조 포함)
3. v1.0 Release Candidate화 착수: 차트 시각화 인프라 + 8곳 연결, 기업 상세 일부(ROIC), 디자인 시스템 1차
4. v1.0 마무리 요청(대시보드/ETF상세/모바일 등) 작업 도중 **변경사항 일부가 파일에 반영되지 않고 유실**
5. 세션 한도로 중단, 실제 파일 상태를 재확인해 이 문서 작성 및 패키징

## ✅ 완료된 기능 (지금 이 ZIP에 실제로 존재함, 테스트로 확인됨)

### 데이터/버그 수정
- 재귀 중첩된 `.github/workflows/...` 폴더 삭제
- 손상된 `DRAM.json` 캐시(200일 미만 이력) 및 manifest 항목 제거
- 낡은 `workspaceKey` 검증 로직을 실제 Google 로그인 UI에 맞게 수정
- `default-tickers.json`에 SPMO/QLD/VUG/SCHQ 추가(단, **실제 데이터 파일은 아직 생성되지 않음** — 아래 참고)

### 검색
- 실시간(입력 중) 검색, 디바운스
- 시가총액 + 거래량 + 이 브라우저 검색빈도(localStorage) 종합 랭킹
- 사전 구축 검색 인덱스로 속도 개선

### 신규 기능 13종
- 기업 종합점수(100점, 5축), 경제적 해자(1~5점), AI 기업요약(규칙기반)
- AI 적정가: EPS 배수법 + PEG + 2단계 FCF DCF, 목표PER/성장률/할인율 직접 조정 가능
- **ROIC 계산(세율 21% 가정, 화면에 가정 명시)** — 리서치 지표 그리드에 포함됨
- 포트폴리오 진단: AI/반도체/빅테크 테마 노출, 국가 비중(보유종목 catalog 기준), 섹터/ETF 중복
- 리스크 시나리오 시뮬레이션(AI -30%, 반도체 -20%, 금리 +1%p, 시장 -10%)
- AI 포트폴리오 코치(규칙기반)
- 종목 비교 업그레이드: PER/PBR/PSR/ROE/영업이익률/순이익률/총부채/FCF/순이익CAGR 비교표
- 배당 계산기, 관심종목(Watchlist), 오늘의 시장 시그널(AI뉴스 대체, 규칙기반)
- 투자일지 업그레이드: 목표가·매수일, 매수 후 6개월/1년(또는 검토일) 경과 시 자동 "복기" 알림
- **AI 어댑터 구조**: `AI_PROVIDERS` / `buildAiPrompt` / `generateAiInsight` — 지금은 규칙 기반이지만 provider만 추가하면 실제 LLM으로 교체 가능하도록 설계

### 차트 시각화 (인프라 + 8곳 연결, 실제 파일에 존재 확인됨)

## ❌ 유실되어 이 ZIP에 없는 것 (전 턴에서 "완료"로 잘못 보고했던 항목)

- **포트폴리오 대시보드 카드** (건강도 게이지, 성장성/배당성/변동성/테마·국가노출/집중도/AI코멘트 요약) — 코드 자체가 파일에 없습니다.
- **ETF 상세의 자체 성과지표** (CAGR/변동성/Sharpe/MDD/베타) — 코드가 없습니다. ETF 상세는 기존 "07 ETF 엑스레이" 수준(운용자산·총보수·상위보유종목·섹터)까지만 있습니다.
- **기업 상세 히어로 가격 영역**(현재가+등락률 크게 표시) — 없습니다.
- **동일 섹터 경쟁사 바로가기** — 없습니다.
- **480px 이하 모바일 전용 CSS** — 없습니다. 900px/800px/700px/640px 등 기존 중간 breakpoint들만 있습니다.
- 이 항목들에 대응하는 `runtime_smoke_test.mjs`의 추가 시나리오 2개도 함께 없습니다(현재 17개 시나리오만 존재).

