# Signal · MyQuantPlatform

API 키 없이 저장된 정적 시장 데이터로 미국 주식·ETF를 검색하고, 리서치·포트폴리오 위험·ETF 실질 노출·A/B 비교·적립식 백테스트를 수행하는 단일 페이지 금융 웹앱입니다.

## 실행

Node.js 22 이상과 Python 3가 필요합니다.

```bash
npm install
npm test
npm run build
npm run serve
```

`http://127.0.0.1:8080`에서 앱을 확인할 수 있습니다. 배포 파일은 `dist/`에 생성됩니다.

## 주요 기능

- 12,339개 미국 상장 종목·ETF 검색 인덱스
- 공백·대소문자·하이픈·점 차이를 흡수하는 검색 정규화와 한글 별칭
- 30개 상세 정적 캐시와 평균 거래량 100만 주 이상 929개 유니버스
- VIG 및 2026년 7월 신규 상장 IQQ 상세 데이터
- 가격·재무·ETF 구성·섹터·국가·출처·갱신 상태 표시
- 기간 수익률, CAGR, 변동성, MDD, Sharpe, Sortino
- ETF 내부 보유분을 펼친 실질 종목·섹터·국가 노출과 중복 분석
- 설명 가능한 포트폴리오 건강도 점수와 감점 근거
- 동일 기간 포트폴리오 A/B 비교
- 실제 저장 가격 경로를 이용한 적립식·일시금 비교
- 로컬 저장, JSON 백업·복원, CSV 내보내기, 선택적 Firebase 로그인
- 480px 이하 전용 모바일 레이아웃과 키보드 검색

## 데이터 구조

```text
data/
├─ catalog.json          검색용 전체 카탈로그
├─ universe.json         거래량 100만 주 기준 유니버스
├─ manifest.json         상세 캐시 목록
├─ default-tickers.json  정기 갱신 대상
└─ market/TICKER.json    종목별 상세 스냅샷
```

브라우저는 외부 유료 시장 API를 호출하지 않습니다. 상세 캐시가 없는 종목은 검색 결과에서 GitHub Actions 생성 요청 경로를 안내합니다. 공급처 오류 시 기존 정상 파일을 덮어쓰지 않습니다.

## 검증

`npm test`는 다음을 한 번에 실행합니다.

- 정적 구조·중복 ID·핵심 기능 마커 검사
- 캐시 스키마·가격 이력·유동성 유니버스·VIG/IQQ 검사
- jsdom 기반 24개 런타임 시나리오

자세한 결과는 [FINAL_VALIDATION_REPORT.md](FINAL_VALIDATION_REPORT.md)를, 데이터와 계산 정의는 [DATA_SOURCES.md](DATA_SOURCES.md), [CALCULATION_METHODS.md](CALCULATION_METHODS.md)를 참고하세요.

## 중요한 제한

- 가격은 저장된 지연 데이터이며 실시간 주문 데이터가 아닙니다.
- 검색 카탈로그 12,339개 전부에 상세 파일이 있는 것은 아닙니다. 현재 상세 캐시는 30개이며 나머지는 온디맨드 생성 대상입니다.
- IQQ는 2026-07-08 상장으로 가격 이력이 짧아 1개월 이상 수익률, CAGR, 연율 변동성, Sharpe, Sortino를 표시하지 않습니다.
- 가격수익률은 배당·환율·세금·수수료를 기본적으로 포함하지 않습니다.
- 적립식의 배당 재투자와 과거 환율은 원천 시계열이 없어 미반영 사실을 화면에 표시합니다.
- AI로 표시된 요약·코치는 외부 생성형 AI가 아니라 저장 데이터에 대한 규칙 기반 설명입니다.
- 본 서비스는 투자 참고용이며 수익을 보장하지 않습니다.
