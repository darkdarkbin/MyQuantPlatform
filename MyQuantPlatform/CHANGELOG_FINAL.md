# 최종 변경 내역

## 오류 수정

- 티커를 빠르게 바꿀 때 이전 요청이 새 화면을 덮는 비동기 경쟁 상태를 차단했다.
- 캐시 미존재·손상 시 이전 종목의 지표, AI 요약, 해자, 적정가, 차트가 남지 않도록 전 패널을 초기화했다.
- `null` 결측값이 0으로 표시되는 전역 숫자 변환 오류를 수정했다.
- ETF에 애널리스트 목표가 0달러가 표시되는 오류를 제거했다.
- 신규 상장 종목의 짧은 가격 이력으로 1년·CAGR·Sharpe 등을 강제 계산하지 않도록 했다.
- 거래량을 소수 주가 아닌 정수 주 단위로 표시했다.
- 360/390px에서 표와 그리드가 문서 폭을 밀어내던 모바일 가로 넘침을 수정했다.
- 중복 섹션 번호를 11~14로 정리했다.

## 데이터·검색

- VIG와 IQQ 상세 캐시를 추가했다.
- IQQ를 NASDAQ 상장 `iShares Nasdaq 100 ETF`로 확인하고 공식 iShares 보유종목 CSV를 적용했다.
- VIG를 NYSE Arca 상장 `Vanguard Dividend Appreciation ETF`로 처리했다.
- 검색 카탈로그를 12,339개로 갱신했다.
- 거래량 100만 주 이상 929개 유니버스와 산정 근거를 `data/universe.json`에 생성했다.
- 공백·대소문자·점·하이픈을 무시하고 `BRK.B`/`BRK-B`, 한글 별칭을 처리한다.
- 키보드 위/아래/Enter 선택과 모바일 검색 레이어를 추가했다.

## 리서치·포트폴리오

- 공통 히어로, 데이터 상태, 가격 차트, 상품/기업 개요, 유사 기업, 버핏형 3문항을 추가했다.
- ETF 운용사, 지수, 상장일, 보수, 구성, 섹터, 국가, 전략 플래그를 표시한다.
- ETF 자체 CAGR·변동성·MDD·Sharpe·Sortino를 충분한 이력에서만 계산한다.
- ETF 내부 구성과 직접 보유를 합산한 실질 종목·섹터·국가 노출을 계산한다.
- 감점 항목과 개선 근거가 보이는 건강도 점수를 추가했다.
- 동일 날짜 범위의 포트폴리오 A/B 비교를 추가했다.
- 실제 가격 경로 적립식, 일시금 비교, 납입일, 리밸런싱 선택, 수수료, 세금, 현금을 추가했다.

## UI/UX

- 어두운 검색 중심 화면을 밝은 카드 기반 금융 UI로 전면 개편했다.
- 색상 토큰, 타이포그래피, 여백, 얕은 테두리와 그림자를 통일했다.
- 480px 이하 전용 레이아웃, 44px 터치 영역, 2열 요약 지표, 내부 표 스크롤을 적용했다.
- 상단 기능 내비게이션과 접근성 라벨·상태 영역을 보강했다.

## 빌드·테스트

- `npm run build`, 이식 가능한 Python 실행 래퍼, 정적 서버를 추가했다.
- 런타임 테스트를 17개에서 24개 시나리오로 확대했다.
- VIG/IQQ, 한글 검색, 설명 가능한 건강도, A/B, 적립식, 결측값, 손상 JSON, 이전 티커 누수를 회귀 검사한다.
- 캐시 검사에 스키마, 유동성 메타데이터, 유니버스, 필수 ETF 검사를 추가했다.

## 호환성

- Node.js 22 이상과 Python 3를 지원한다.
- 앱은 정적 HTML/JSON 구조를 유지해 GitHub Pages 배포 방식을 보존한다.
- 기존 포트폴리오, 리밸런싱, 백테스트, 비교, 일지, 배당, 관심종목, 시그널, 로컬·Firebase 저장 기능을 유지했다.
