# MyQuantPlatform 감사 보고서

감사 기준일: 2026-07-25

## 감사 범위

저장소 전체 디렉터리, 실행 방식, 데이터 수집·캐시, 검색, 종목/ETF 리서치, 포트폴리오, 차트, 계산 함수, 모바일 CSS, 테스트, GitHub Actions를 확인했다. 구현 전 원본은 로컬 Git 기준선 커밋 `6564a17`로 보존했다.

## 최초 확인 결과

1. 루트와 `MyQuantPlatform/` 아래에 서로 다른 세대의 앱이 중복되어 실제 배포 대상을 오인할 위험이 있었다.
2. 더 최신 기능은 중첩 폴더의 HTML에 있었지만 루트 GitHub Actions는 오래된 루트 파일을 대상으로 했다.
3. 상세 캐시는 28개였고 검색 카탈로그는 약 12,300개였으나 거래량 기준 유니버스 파일이 없었다.
4. VIG와 IQQ 상세 캐시가 없었다.
5. `npm test`는 있었지만 `npm run build`가 없었고, Python 실행 이름이 운영체제에 종속적이었다.
6. 런타임 스모크 테스트는 17개 시나리오였으며 실제 브라우저 반응형 검증 결과가 없었다.
7. 리서치 요청 전환을 취소하는 장치가 없어 빠른 티커 전환 시 이전 응답이 섞일 여지가 있었다.
8. 결측값 표시, 신규 상장 짧은 이력, 거래량 100만 주 기준을 일관되게 설명하는 메타데이터가 부족했다.
9. 모바일에서 검색 레이어, 표, 그리드의 가로 넘침 위험이 있었다.
10. 기존 `CURRENT_PROGRESS.md`에는 실제 HTML에 없거나 덜 구현된 기능이 완료로 기록된 부분이 있었다.

## 실제 브라우저 감사에서 발견한 추가 결함

- 존재하지 않는 티커를 연 뒤 AI 요약 등 일부 하위 카드에 직전 VIG 데이터가 남았다.
- `Number(null)`의 결과가 0인 점 때문에 IQQ의 AUM·배당수익률·베타 결측값이 거짓 0으로 표시됐다.
- 360px와 390px에서 `.scroll-table`과 그리드 최소 너비 때문에 문서 전체가 가로로 넘쳤다.
- 배당 계산기 이후 섹션 번호가 A/B 비교와 중복됐다.
- ETF에도 애널리스트 목표가 0달러가 있는 것처럼 표시되는 경우가 있었다.

## 구조상 위험과 조치

| 위험 | 조치 |
|---|---|
| 중첩 프로젝트 중복 | 최종 루트를 단일 실행 프로젝트로 정리 |
| 공급처 일시 실패로 정상 캐시 손실 | 임시 메모리에서 완성 후 성공 시에만 파일 교체, 실패 시 기존 파일 유지 |
| 짧은 이력으로 장기 수익률 강제 계산 | 기간의 80% 이상 데이터가 있을 때만 기간 수익률 생성 |
| 티커 전환 경쟁 상태 | `AbortController`와 요청 순번으로 최신 요청만 렌더링 |
| 결측값의 거짓 0 표시 | `null`, `undefined`, 빈 문자열, 불리언을 숫자 변환 전에 차단 |
| 전체 앱 중단 | 카드별 빈 상태·오류 상태로 격리 |
| 거래량 기준 모호성 | 20일 평균 → 30일 평균 → 공급처 평균 → 최근 정상일 순으로 명시 |
| 브라우저/모바일 미검증 | 실제 인앱 브라우저로 핵심 흐름과 7개 폭 검증 |
