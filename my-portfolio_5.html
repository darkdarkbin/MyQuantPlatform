01 투자 금액 설정

총 투자금액을 입력하면 종목별 목표비중에 따라 배분 금액이 자동 계산됩니다.

02 종목 비중 입력

시세는 네이버증권/구글 파이낸스 등에서 확인 후 직접 입력해 주세요. (현재가는 나중에 계속 업데이트하면서 쓰시면 됩니다)

종목 목표비중 배분금액 보유수량 평가금액 현재비중 손익률 리밸런싱 관리
아직 추가된 종목이 없습니다. 위에서 종목을 추가해 보세요.

03 자산 배분

목표비중 기준 자산 배분 현황입니다.

-
총 투자금액

04 리밸런싱 요약

설정한 총 투자금액을 기준으로, 목표비중에 맞추려면 필요한 매매량을 계산합니다.

05 위험도 분석 · 백테스팅

각 종목 카드의 "과거 가격 입력"을 눌러 과거 종가를 붙여넣으세요 (오래된 날짜 → 최근 날짜 순, 한 줄에 하나씩). 네이버증권 종목 페이지의 <시세> 탭이나 구글에 "AAPL historical prices" 검색 후 표에서 종가만 복사해 붙여넣으면 됩니다. 모든 종목의 데이터 개수(줄 수)를 똑같이 맞춰서 입력해야 정확히 계산됩니다 (예: 전 종목 60줄 = 최근 60거래일).

과거 가격을 입력하고 실행 버튼을 누르면 여기에 결과가 표시됩니다.

06 저장 · 불러오기

입력 내용은 이 브라우저에 자동 저장됩니다. 다른 기기로 옮기거나 백업할 때는 JSON 파일을 이용하세요.

사용법: 이 파일(my-portfolio.html)은 인터넷 브라우저(크롬/엣지 등)로 더블클릭해서 여는 것만으로 바로 작동합니다. VS Code는 파일을 보관/편집하는 용도일 뿐, 이 웹사이트 자체는 npm 설치나 서버 실행 없이 이 파일 하나로 완성되어 있습니다.

실시간 시세 자동 조회가 안 되는 이유: 무료 주식 API 대부분이 브라우저에서 직접 호출하는 것을 보안상 차단합니다(CORS 정책). 이걸 뚫으려면 별도의 서버(백엔드)가 필요한데, 이는 "파일 하나로 끝"이라는 지금 목표와는 다른 작업입니다. 지금은 시세를 직접 입력하는 방식으로, 나중에 필요하시면 자동 조회 버전도 만들어 드릴 수 있습니다.
