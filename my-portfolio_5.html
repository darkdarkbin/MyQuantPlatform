09 개인 보관함 · 저장

보관함 키마다 포트폴리오와 메모가 분리되어 이 브라우저에 자동 저장됩니다.

현재: 기본 보관함 · 이 기기와 브라우저 안에서만 작동합니다.

사용법: 이 파일(my-portfolio.html)은 인터넷 브라우저(크롬/엣지 등)로 더블클릭해서 여는 것만으로 바로 작동합니다. VS Code는 파일을 보관/편집하는 용도일 뿐, 이 웹사이트 자체는 npm 설치나 서버 실행 없이 이 파일 하나로 완성되어 있습니다.

무료 시세 안내: GitHub Actions가 공개 시장 페이지의 지연 데이터를 하루 한 번 저장하고 사이트는 그 파일만 읽습니다. 공급처 구조 변경이나 일시 차단 시 기존 캐시를 유지하며, 일부 지표가 비어 있으면 ‘정보 없음’으로 표시합니다. 보관함 키는 서버 로그인이나 암호화 계정이 아니므로 다른 기기에서는 JSON 백업이 필요합니다. 계산 결과는 투자 판단을 위한 참고 자료이며 수익을 보장하지 않습니다.
