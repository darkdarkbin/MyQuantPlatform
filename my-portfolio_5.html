05 위험도 분석 · 백테스팅

종목과 목표비중만 준비한 뒤 실행하세요. 과거 종가를 자동 조회하고 공통 거래일을 맞춰 변동성·MDD·수익률·베타를 계산합니다.

무료 API 키 발급 ↗

API 키는 GitHub나 백업 파일에 포함하지 않고 이 브라우저에만 저장합니다. 국내 종목은 데이터 제공 범위에 따라 자동 조회가 지원되지 않을 수 있습니다.

자동 조회가 안 되는 종목만 수동으로 입력

오래된 날짜부터 최근 날짜 순서로 종가를 한 줄에 하나씩 입력하세요. 날짜가 없는 수동 데이터끼리는 최근 값 기준으로 길이를 맞춰 계산합니다.

06 분산 진단 · ETF 엑스레이

ETF 내부 보유종목까지 펼쳐 실질 종목 노출, ETF 중복률, 섹터 집중도를 확인합니다.

FMP 키를 설정하고 진단을 실행하면 결과가 표시됩니다. 개별 주식은 자동으로 직접 노출 100%로 반영됩니다.

07 투자 일지 · 매수 근거

수익률보다 먼저 매수 이유와 매도 조건을 기록하고, 나중에 그 가정이 유효한지 검토합니다.

08 저장 · 불러오기

입력 내용은 이 브라우저에 자동 저장됩니다. 다른 기기로 옮기거나 백업할 때는 JSON 파일을 이용하세요.

사용법: 이 파일(my-portfolio.html)은 인터넷 브라우저(크롬/엣지 등)로 더블클릭해서 여는 것만으로 바로 작동합니다. VS Code는 파일을 보관/편집하는 용도일 뿐, 이 웹사이트 자체는 npm 설치나 서버 실행 없이 이 파일 하나로 완성되어 있습니다.

자동 시세 안내: Twelve Data에서 과거 일별 종가를 조회합니다. 무료 호출 한도나 데이터 제공 범위 때문에 일부 종목이 실패할 수 있으며, 이 경우 05번의 수동 입력을 예비 방법으로 사용할 수 있습니다. 계산 결과는 투자 판단을 위한 참고 자료이며 수익을 보장하지 않습니다.
